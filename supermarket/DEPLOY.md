# העלאה לשרת

המדריך מניח שרת לינוקס (אובונטו/דביאן) עם גישת root או sudo.

## לפני שמתחילים

- **השרת צריך להיות בישראל.** רוב אתרי הרשתות חוסמים גישה מחו״ל (קרפור, ויקטורי, מחסני השוק, חצי חינם,
  סופר-פארם ורשתות קטנות). משרת בחו״ל ייטענו רק שופרסל והרשתות שב-Cerberus.
- **דומיין** (או תת-דומיין) שמצביע לכתובת ה-IP של השרת. בלי HTTPS הדפדפן לא נותן גישה למצלמה, וסריקת הברקוד לא תעבוד.
- **משאבים:** 2 ליבות, 2GB זיכרון ו-20GB דיסק מספיקים לטעינה לפי רדיוס. טעינה ארצית מלאה (`INGEST_ALL_STORES=true`) דורשת הרבה יותר דיסק וזמן.
- פורטים 80 ו-443 פתוחים לעולם. שום פורט אחר לא צריך להיות פתוח.

## התקנה

```bash
curl -fsSL https://get.docker.com | sh
```

```bash
git clone https://github.com/nurit-pixel/election.git /opt/election
```

```bash
ln -s /opt/election/supermarket /opt/supermarket && cd /opt/supermarket
```

```bash
cp .env.example .env && nano .env
```

מה חובה לשנות ב-`.env`:

| משתנה | ערך |
|---|---|
| `POSTGRES_PASSWORD` | סיסמה אקראית ארוכה |
| `FAMILY_PASSWORD` | הסיסמה המשפחתית לכניסה |
| `SESSION_SECRET` | מחרוזת אקראית (למשל הפלט של `openssl rand -hex 32`) |
| `APP_DOMAIN` | הדומיין, למשל `sal.example.org` |
| `APP_URL` | `https://` + הדומיין (לקישור במייל) |
| `WEB_BIND` | `127.0.0.1` (האפליקציה נגישה רק דרך Caddy) |

למייל היומי המרוכז: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`, `ALERT_EMAIL_TO`.
בלי אלה ההתראות מופיעות רק באפליקציה.

הפעלה:

```bash
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
```

Caddy מוציא תעודת HTTPS לבד בהפעלה הראשונה (דורש שהדומיין כבר מצביע לשרת).

## מה קורה בהפעלה הראשונה

1. ה-worker מוריד את רשימות הסניפים של כל הרשתות (כמה דקות).
2. Geocoding לכל הסניפים רץ ברקע: בקשה כל 1.5 שניות ל-Nominatim, כמה שעות לכל הארץ, פעם אחת בלבד.
   אם השירות מגביל (429), ה-worker ממתין וממשיך לבד.
3. נכנסים לאפליקציה, ובמסך **הגדרות** מוסיפים כתובת ורדיוס. המחירים והמבצעים של הסניפים שלידה נטענים מיד
   (סניפים שעוד לא אותרו יצטרפו כשה-geocoding יסתיים).

## הריצה הלילית

כל יום ב-`NIGHTLY_TIME` (ברירת מחדל 06:00, שעון ישראל) ה-worker מריץ לבד:

1. רשימות סניפים של כל הרשתות.
2. מחירים ומבצעים לסניפים שברדיוס (או לכל הארץ עם `INGEST_ALL_STORES=true`).
3. היסטוריית מחירים והתראות.
4. המייל היומי המרוכז.
5. ניקוי רישומים ישנים מ-`RETENTION_DAYS` ימים.

כשל ברשת אחת לא עוצר את השאר: המחירים הקודמים שלה נשארים, והיא מסומנת "לא עודכן" במסך ההגדרות.
אם השרת היה כבוי ב-06:00, הריצה מתבצעת כשהוא עולה. אין ריצה כפולה באותו יום.

המצב מוצג במסך ההגדרות ("סטטוס טעינה"), וגם:

```bash
docker compose exec ingest python -m ingest status
```

הרצה ידנית של הריצה הלילית המלאה:

```bash
docker compose exec ingest python -m ingest nightly
```

## תחזוקה

לוגים:

```bash
docker compose logs -f --tail 100 ingest
```

עדכון גרסה:

```bash
git pull && docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
```

גיבוי המסד (נשמר ב-`backups/`, 14 אחרונים):

```bash
./scripts/backup.sh
```

גיבוי יומי אוטומטי, שורה ב-`crontab -e` של השרת:

```
30 7 * * * cd /opt/supermarket && ./scripts/backup.sh >> backups/backup.log 2>&1
```

שחזור מגיבוי (מוחק את הנתונים הקיימים):

```bash
gunzip -c backups/supermarket-YYYYMMDD-HHMM.sql.gz | docker compose exec -T db psql -U supermarket -d supermarket
```

את השחזור מריצים על מסד ריק: `docker compose down`, מחיקת ה-volume `supermarket_pgdata`, `docker compose up -d db`, ואז הפקודה.

## פתרון תקלות

| תופעה | מה לבדוק |
|---|---|
| רשת מסומנת "נכשל" | הודעת השגיאה מופיעה מתחתיה במסך ההגדרות. "לא התקבלו קבצים מהאתר" משרת בישראל פירושו שהאתר של הרשת לא זמין כרגע או שינה מבנה; הריצה הבאה תנסה שוב. |
| רשת מסומנת "לא עודכן" | יש לה מחירים, אבל הם ישנים מ-36 שעות או שהטעינה האחרונה נכשלה. |
| כתובת "לא נמצאה" | לכתוב רחוב, מספר ועיר. |
| הרבה סניפים "במיקום משוער" | שירות ה-geocoding לא מצא את הכתובת המדויקת ומיקם לפי העיר. אפשר להחליף שירות ב-`GEOCODER_URL` (כל שירות תואם Nominatim). |
| סריקת ברקוד לא נפתחת | האתר חייב להיות ב-HTTPS, ולאשר לדפדפן גישה למצלמה. |
| לא מגיע מייל | `docker compose exec ingest python -m ingest digest` מדפיס אם נשלח; לבדוק את `SMTP_*` ו-`ALERT_EMAIL_TO`. |
| שכחתם את הסיסמה | לשנות `FAMILY_PASSWORD` ב-`.env` ולהריץ שוב את פקודת ההפעלה. כל המכשירים יתנתקו. |

## מה נבדק ומה לא

נבדק בסביבת הפיתוח: התקנה נקייה ממסד ריק, הריצה הלילית מקצה לקצה (כולל השלמה אחרי שהשרת היה כבוי, ובלי ריצה כפולה),
HTTPS דרך Caddy עם תעודה מקומית (כולל הפניה מ-HTTP ועוגיית כניסה מאובטחת), וגיבוי עם שחזור.

הפיתוח נעשה בסביבת ענן מחוץ לישראל, ולכן הדברים הבאים צריכים בדיקה ראשונה על השרת:

- 19 הרשתות שחסומות מחו״ל (קרפור/יינות ביתן/מגה, ויקטורי, מחסני השוק, חצי חינם, סופר-פארם, גוד פארם, ורשתות Bina).
  הן נטענות עם `il-supermarket-scraper`; אם רשת נכשלת גם מהשרת, השגיאה תופיע במסך ההגדרות.
- תעודת HTTPS אמיתית מ-Let's Encrypt על הדומיין שלכם, וסריקת ברקוד במצלמה של טלפון.
- שליחת מייל דרך שרת SMTP אמיתי (נבדקה רק מול שרת דואר מקומי).
